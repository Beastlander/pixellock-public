# PixelLock

Downloads, bug reports and ideas for [PixelLock](https://beastlander.github.io/pixellock-public/), a screenshot and screen recording app for Windows.

## Download

**[Download PixelLock for Windows](https://github.com/Beastlander/pixellock-public/releases/latest/download/PixelLock-Setup-x64.exe)** or pick a version under [Releases](../../releases). The installer is not code signed yet, so Windows SmartScreen asks once: click **More info**, then **Run anyway**. The app updates itself after that. A Microsoft Store version is coming.

## Feedback

The easiest way to send feedback is from the app: **Send feedback** in the main window or in the tray menu. It opens a prefilled issue here; check it and press **Create**.

You can also [open an issue](../../issues/new/choose) directly.

## What happens next

Every issue is read and triaged within a few days. We label it, may ask a question, and add it to the product backlog. We comment here when it ships.

## Please

- Issues here are **public**. Don't include passwords, keys or personal information, and check screenshots before pasting them.
- Found a security problem? Don't post details here; open an issue saying you have a security report and we'll contact you.
- One issue per bug or idea. Search first, and add a 👍 to an existing issue instead of a duplicate.
