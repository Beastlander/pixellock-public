Privacy

PixelLock keeps your captures on your computer.

What PixelLock does not do

PixelLock has no account, no analytics and no tracking. Screenshots and recordings are saved only where you choose, and are never uploaded by the app.

What PixelLock keeps on your computer

  • Screenshots (PNG) in Pictures\PixelLock and recordings (MP4, no audio) in Videos\PixelLock.
  • With Copy to the clipboard on (the default), each screenshot is also copied to the Windows clipboard. PixelLock never reads your clipboard.
  • Your settings (hotkeys and output options), in %APPDATA%\com.beastlander.pixellock.

When PixelLock uses the internet

  • Update check (direct download only): the app downloads latest.json from GitHub to see if there is a new version. GitHub receives your IP address, as with any web request. The Microsoft Store version leaves updates to the Store and does not do this.
  • Feedback: when you press Send in the feedback form, the app sends what you wrote, and the kind of feedback you picked, to the PixelLock team. It goes through our own small service on Cloudflare into a private list that only the team can read. No account or name is sent. Adding your email is optional: if you do, it is kept with that feedback in our private issue list on GitHub and used only to reply about it. To have it deleted, contact us (see below), and we will delete it, including GitHub's edit history. The app remembers it on your computer so you don't have to type it again; send feedback with the field empty to forget it. Like any web request, Cloudflare sees your IP address; our service uses it only to limit how many messages can be sent per minute and does not store it. System info (app version, Windows version) is included only if you tick the box. If you choose to post on GitHub instead, the app opens a prefilled public GitHub issue in your browser, and nothing is posted until you press Create there.

Optional AI features

If future versions add AI features, they will be off by default, and this page will say what is sent and to whom before you can turn them on.
